# 更新记录

## 0.10.0 — 2026-11-03

- 增加主对话和子代理独立的关闭、开启、查询命令，以及主代理可调用的本地控制工具。
- 手动开关持久保存，正常续做、重载及失败恢复不会自动重新开启。
- 查询同时返回保活开关、宿主状态、模型、次数和在途信息，不自动判断业务是否结束。
- 状态写入顺序执行，保存失败明确提示；发送前再次检查开关，迟到结果保留计量与通知过滤。
- 保留既有间隔、每轮次数上限、额度保护和发布规范。
