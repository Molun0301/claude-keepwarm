# keepwarm 保活派生版 0.11.0

整理开关：删除与无参数 `off/on` 重复的 `/keepwarm pause/resume`，`/keepwarm` 与 `/keepwarm status` 输出同一份状态。主代理工具的 `off/on` 必须写明 `agent_id`，主对话用 `main`；整个会话插件只由用户执行 `/keepwarm off` 或 `/keepwarm on`。

修复只写 5 分钟缓存的会话按 1 小时假设保活、每次必然未命中并整段重写缓存的问题。插件在每轮工作结束后读取该对话转录末尾的实际缓存有效期，5 分钟对话不再保活，切回 1 小时后自动恢复。主对话保活长时间无返回时不再阻塞其他对话保活。

运行中会话更新后执行 `/reload-plugins`。验证使用离线替身和本机模拟接口，没有发送真实模型请求；实际缓存效果与真实额度窗口仍需按运行环境确认。
